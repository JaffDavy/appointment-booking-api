Schedule Sync API

This is the API server for Schedule Sync. Use Thunder Client to test the following endpoints:

1. GET  http://localhost:3000/api/test
2. POST http://localhost:3000/api/auth/register
3. POST http://localhost:3000/api/auth/login

Register Example:

POST http://localhost:3000/api/auth/register
Content-Type: application/json

{
  "name": "Test User",
  "email": "test@example.com",
  "password": "password123",
  "role": "user"
}

Login Example:

POST http://localhost:3000/api/auth/login
Content-Type: application/json

{
  "email": "test@example.com",
  "password": "password123"
}
