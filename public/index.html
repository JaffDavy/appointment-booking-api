Authentication Endpoints

POST /api/auth/register

Body: {
    "name": "John Doe",
    "email": "john@example.com",
    "password": "password123",
    "role": "user" // or "provider"
}

POST /api/auth/login

Body: {
    "email": "john@example.com",
    "password": "password123"
}

GET /api/auth/me

Headers: x-auth-token: YOUR_JWT_TOKEN

Time Slot Management Endpoints

POST /api/timeslots

Headers: x-auth-token: PROVIDER_JWT_TOKEN

Body: {
    "startTime": "2024-04-26T10:00:00Z",
    "endTime": "2024-04-26T11:00:00Z"
}

GET /api/timeslots/provider/:providerId

Get all available time slots for a specific provider

GET /api/timeslots/appointments

Headers: x-auth-token: YOUR_JWT_TOKEN

Get all appointments for the current user (or all time slots if provider)

POST /api/timeslots/:timeSlotId/book

Headers: x-auth-token: USER_JWT_TOKEN

Book a specific time slot

POST /api/timeslots/:timeSlotId/cancel

Headers: x-auth-token: YOUR_JWT_TOKEN

Cancel a booked appointment (can be done by the booker or provider)

Real-time Notifications

Connect to WebSocket to receive real-time notifications about appointments:

// Client-side code
const socket = io('http://localhost:3000');

// Join your user-specific notification room
socket.emit('join', `user_${userId}`);

// Listen for notifications
socket.on('notification', (data) => {
  console.log('Notification:', data);
});
